Cassandra Cluster: Scalable data storage for smooth information flow.
Cassandra Cluster là một distributed system dựa trên non-relational database gọi là Apache Cassandra, để lưu trữ và truy vấn data trên nhiều máy chủ (nodes).
1 Cassandra Cluster gồm nhiều máy chủ (nodes) hoạt động cùng nhau để lưu trữ và xử lý dữ liệu. Mỗi node trong cluster chịu trách nhiệm lưu và xử lý 1 phần data.

Apache Spark Streaming Cluster: Powers real-time data processing.
Apache Spark Streaming Cluster là distributed system dựa trên Apache Spark, 1 framework xử lý dữ liệu phân tán. Nó được thiết kế để xử lý dữ liệu dòng (streaming data) trong thời gian thực. Một Apache Spark Streaming Cluster bao gồm nhiều máy chủ (nodes) hoạt động cùng nhau để xử lý dữ liệu dòng. Mỗi node trong cluster chịu trách nhiệm xử lý một phần dữ liệu dòng và thực hiện các phân tích và tính toán trên dữ liệu đó. Dữ liệu dòng được chia thành các batch nhỏ và xử lý song song trên các node để đảm bảo hiệu suất cao.

Hadoop Cluster: Mines insights from vast data to drive e-commerce strategies.
Hadoop Cluster là 1 distributed system dựa trên Apache Hadoop, 1 framework mã nguồn mở được sử dụng để lưu trữ và xử lý dữ liệu lớn. Nó được thiết kế để xử lý và phân tán dữ liệu trên nhiều máy chủ (nodes).
Hadoop Cluster sử dụng Hadoop Distributed File System (HDFS) để lưu trữ dữ liệu và Apache MapReduce để xử lý dữ liệu phân tán. Hadoop Cluster được sử dụng rộng rãi trong các ứng dụng có yêu cầu về xử lý và lưu trữ dữ liệu lớn như trí tuệ nhân tạo và học máy. 

Kafka: Facilitates data communication within the system.
Kafka trong hệ thống này là 1 phần giúp data được truyền tải giữa các component chính. Khác với hệ thống Apache kafka.
Apache Kafka là một hệ thống phân tán mã nguồn mở để xây dựng ứng dụng xử lý dữ liệu thời gian thực. Kafka được thiết kế như một hệ thống nhật ký phân tán (distributed log) và có thể xử lý hàng trăm nghìn hoặc thậm chí hàng triệu tin nhắn mỗi giây.
Producer gửi tin nhắn vào Kafka, consumer subscribe tin nhắn từ Kafka. Topic là một danh mục các records được lưu trữ và phân loại. Mỗi record bao gồm một key, một value và một timestamp.
Kafka cluster gồm một hoặc nhiều máy chủ (server) được gọi là brokers. Mỗi broker có thể xử lý hàng nghìn tin nhắn mỗi giây và hỗ trợ nhiều client cùng lúc, realtime data.
